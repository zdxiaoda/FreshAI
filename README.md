# 中文标点符号修正器

一个基于 Vue 3 + MDUI 的前端网页应用，用于将 AI 生成的半角标点符号转换为中文全角标点符号。

## ✨ 功能特性

- 📄 **多格式支持**：支持读取 TXT、Markdown、DOCX 文件
- 🔄 **智能转换**：自动将半角标点转换为中文全角标点
- 📊 **对比显示**：左右分栏显示原文和转换后内容，高亮修改部分
- 🎨 **美观界面**：采用 Material Design 风格，支持亮色/暗色主题
- 📋 **一键复制**：快速复制转换后的内容
- 💾 **下载功能**：支持下载转换后的文件

## 🚀 快速开始

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

访问 http://localhost:5173 查看应用。

### 构建生产版本

```bash
npm run build
```

## 📖 使用说明

1. **上传文件**
   - 拖拽文件到上传区域
   - 或点击上传区域选择文件
   - 支持的格式：`.txt`, `.md`, `.docx`

2. **选择转换选项**
   - 转换引号：`"` → `""` 、`'` → `''`
   - 转换逗号：`,` → `，`
   - 转换句号：`.` → `。`
   - 转换其他标点：`;` `:` `?` `!` 等

3. **开始转换**
   - 点击"开始转换"按钮
   - 查看转换结果和修改统计

4. **导出结果**
   - 点击"复制"按钮复制到剪贴板
   - 点击"下载"按钮保存为文件

## 🔧 转换规则

| 原始符号 | 转换后 | 说明 |
|---------|--------|------|
| `"` | `"` 或 `"` | 双引号（根据上下文判断开闭） |
| `'` | `'` 或 `'` | 单引号 |
| `,` | `，` | 逗号 |
| `.` | `。` | 句号 |
| `;` | `；` | 分号 |
| `:` | `：` | 冒号 |
| `?` | `？` | 问号 |
| `!` | `！` | 感叹号 |
| `(` | `（` | 左圆括号 |
| `)` | `）` | 右圆括号 |
| `[` | `【` | 左方括号 |
| `]` | `】` | 右方括号 |
| `...` | `…` | 省略号 |

## 🛠️ 技术栈

- **前端框架**：Vue 3 + Composition API
- **构建工具**：Vite
- **UI 组件库**：MDUI 2 (Material Design)
- **文件处理**：
  - Markdown：marked.js
  - DOCX：mammoth.js
  - TXT：原生 FileReader API


## 🎨 主题切换

应用支持亮色和暗色两种主题：
- 点击右上角的主题切换开关
- 自动跟随系统主题偏好
- 主题设置会保存在本地存储中

## 📝 注意事项

- 文件大小限制：10MB
- 支持的文件编码：UTF-8
- 转换时会保留原始格式（如 Markdown 语法）
- 小数点不会被转换为句号
